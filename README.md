Sistema de Pedidos para Restaurante — Byte a Byte

Projeto da disciplina de POO. Integrantes: Carlos Eduardo Lopes de Rodrigues,
Leonardo Lague Bachernitsan e Pedro Villela Monteiro.

## Como executar

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py                   # interface gráfica
python main.py --demo            # demonstração no terminal
python -m pytest                 # testes
```
